# AI 하이퍼스케일 데이터센터 최적입지 — 거시분석 결과 스토리라인

> 분석 기준: 전국 144개 시군구 / 5개 피처 / rank_norm 정규화 / 가중치 합산

---

## 1. 왜 거시분석인가

하이퍼스케일 데이터센터(100MW급 이상)는 단순히 땅이 넓어서 되는 게 아니다.  
입지 선택에는 **지역 단위에서만 평가 가능한 구조적 조건**이 존재한다.

| 질문 | 지역 단위로 봐야 하는 이유 |
|---|---|
| 전기는 충분한가? | 변전소 송전망 여유용량은 행정구역 단위로 집계 |
| 재해에서 안전한가? | 지진·홍수·산사태 위험은 광역 지형 패턴에 따름 |
| 냉각수는 구할 수 있나? | 취수여유율은 유역(수계) 단위로 결정 |
| 재생에너지 PPA 가능한가? | 신재생 발전량은 권역별 부존자원에 의존 |
| 서울 수요와 연결되나? | 네트워크 지연은 직선거리의 함수 |

거시분석은 이 5가지 질문에 **전국 비교 점수**를 부여해 후보지를 15개로 좁힌다.

---

## 2. 피처 & 가중치 설계

```
전력 35% + 재해 20% + 냉각 20% + 신재생 20% + 네트워크 5% = 100%
```

### 전력 (35%) — 가장 높은 이유

데이터센터는 전력이 없으면 하루도 운영이 불가능하다.  
단순 발전량이 아닌 **"지금 당장 끌어올 수 있는 여유 용량"** 을 본다.

- 지표: `전력공급여유량(2032) × 합산_송전망용량(2032)`
- 두 값 모두 높아야 실제 연결 가능 → AND 조건으로 곱셈 처리

### 재해 (20%) — 안전 마진

운영 중단은 곧 천문학적 손실.  
**낮을수록 좋은** 역지표: 지진(30%) + 홍수(26%) + 산사태(20%) + 해안침수(12%) + 산불(12%)

### 냉각 (20%) — 물과 기온

- 취수여유율(60%): 냉각수 끌어올 여력
- 연간 15°C 이하 일수(40%): 외기냉각(Free Cooling) 가능 일수 → 전력비 절감

### 신재생 (20%) — RE100 대응

글로벌 빅테크는 RE100 선언 완료. 근처에서 PPA 체결 가능한 신재생 용량이 많을수록 유리.

### 네트워크 (5%) — 서울 접근성

가중치는 낮지만, 동일 점수일 때 수도권과의 거리가 결정적 변수.

## 3. 전국 분포 패턴

144개 시군구를 분석한 결과, **상위 15개 지역이 특정 권역에 집중**됐다.

```
충청권  7개  (충북 5 + 대전 3)
강원권  3개  (강릉·춘천·원주)
호남권  3개  (정읍·군산·광주)
영남권  2개  (포항 2)
```

**수도권이 0개인 이유**: 전력 여유용량 포화, 재해 취약, 부지 고비용.  
**충청·강원 집중 이유**: 전력망 여유 + 냉각수 수계 + 서울 접근성의 교집합.

## 4. Top 15 결과 — 지역별 스토리

### 🥇 1위 강원 강릉시 (74.7점)

**핵심 강점: 신재생 에너지 부존량 1위 (94점)**

동해안 풍력 + 강원 태양광의 집결지. RE100 이행에 가장 유리한 입지.  
다만 **재해 점수 41점(하위권)** — 동해안 지진 위험 + 해안 침수 리스크 존재.  
→ 재해 저감 설계 필수. 신재생 PPA 경쟁력은 압도적.

### 🥈 2위 충북 청주시청원구 (72.8점)

**핵심 강점: 전력 인프라 최상위권 (91점) + 네트워크 (90점)**

오창산업단지 + 청주변전소 인프라. 기업 입지 경험 다수.  
**냉각 점수 32점** — 미호강 취수여유율 제한, 외기 냉각일수 부족.  
→ 공냉식 보조 시스템 필수 투자.

### 🥉 3위 강원 춘천시 (71.6점)

**핵심 강점: 네트워크(서울 접근성) 전국 1위 (99점) + 냉각(77점)**

서울~춘천 고속도로 직결. 북한강 수계 냉각수 풍부.  
**재해 점수 57점** — 중간 수준, 관리 가능 범위.  
→ 미시분석에서도 최종 1위로 확정. 거시·미시 모두 최상위.

### 4위 충북 진천군 (71.0점)

**신재생 47점** — 충청 내륙 특성상 풍력 자원 한계.

### 5위 충북 음성군 (69.8점)

**핵심 강점: 전력 전국 최상위 (94점)**

음성~충주 변전소 밀집. 국가산업단지 인프라 활용 가능.  
**재해 39점** — 특히 홍수 리스크 주의(음성천·청미천 유역).

## 5. 핵심 발견 3가지

### 발견 1: "전력 vs 신재생" 트레이드오프

전력 여유용량이 높은 지역(충청·대전)과  
신재생 발전량이 많은 지역(강원·호남)이 서로 다르다.

```
전력 상위권: 대전(98~99점), 음성(94점), 청주(91점)
신재생 상위권: 강릉(94점), 정읍(87점), 군산(88점)
```

→ RE100을 최우선시하면 강릉·정읍, 전력 안정성 우선이면 대전·청주.

### 발견 2: 대전의 역설

대전 3개 구(중·서·동)가 모두 Top10 진입했지만, **신재생 점수 12~16점**으로 전국 최하위권.  
도시지역 특성상 신재생 부존자원이 거의 없다.  
→ RE100 의무화 추세에서 장기 리스크 존재. 단기 전력 안정성은 최고.

### 발견 3: 충청북도의 독주

Top15 중 충청북도가 5개 (청주청원·진천·음성·상당·충주).  
이유: 경부선 전력망 축 + 미호강 수계 + 서울 2시간 이내.  
→ 국내 데이터센터 입지 최적 권역으로 충청권이 수렴.

## 6. 민감도 분석 요약

5,000회 Monte Carlo 시뮬레이션 결과:

- 평균 Top10 겹침: **7.39/10개 (74%)**
- Top10 8개 이상 유지 확률: **47.8%**
- 가장 안정적인 후보: 강릉(95%), 진천(93%), 청주청원(91%)
- 가장 불안정한 후보: 대전 3구 (50~67%) — 신재생 가중치 변화에 민감

> **결론**: 현재 Top5 (강릉·청주청원·춘천·진천·음성)는 가중치가 상당히 변해도 유지된다.

## 7. 거시 → 미시 연계

거시분석 상위 15개 지역을 후보지로 확정하고,  
미시분석(250m 격자 BFS+Spectral 클러스터링)으로 **실제 부지 위치**를 특정했다.

| 거시순위 | 지역 | 미시순위 | 미시 클러스터 |
|---|---|---|---|
| 3위 | 강원 춘천시 | **1위** | 신북읍 일대 1265격자 / 4,744ha |
| 1위 | 강원 강릉시 | **2위** | 성산면 일대 494격자 / 1,852ha |
| 5위 | 충북 음성군 | **3위** | 금왕읍 일대 829격자 / 3,109ha |
| 4위 | 충북 진천군 | **4위** | 이월면 일대 277격자 / 1,039ha |
| 2위 | 충북 청주시청원구 | **5위** | 오창읍 일대 802격자 / 3,008ha |

거시 1위(강릉)가 미시에서 2위로 밀린 이유:  
**재해 점수(41점)** + 실제 건축 가능 격자 수 제한.

## 9. 분석 대상 지역 설정 기준

### 9-1. 수도권 제외 근거

서울특별시, 인천광역시, 경기도는 분석 대상에 포함했으나 결과적으로 **Top 20에 단 1개도 진입하지 못했다.**

| 항목 | 수도권 현황 |
|---|---|
| 전력 여유용량 | 수도권 계통 포화 상태 (여유용량 하위권) |
| 부지 비용 | 비수도권의 10~50배 (직접 반영 안 됐으나 실질 제약) |
| 주민 민원 | 도시 밀집지역 → 데이터센터 건설 반대 심함 |
| 냉각수 | 한강 취수 경쟁 심화 |
| 재해 | 홍수·침수 취약 |

### 9-2. 섬 지역 제외 근거

제주도 및 서해·남해 도서 지역(인천 옹진군, 전남 신안군 등):

| 제외 사유 | 설명 |
|---|---|
| 전력망 독립 계통 | 제주는 HVDC 해저케이블만 연결 → 154kV+ 송전망 여유 없음 |
| 물류 불가 | 서버 장비 반입 시 선박 의존 → 운영비 급등 |
| 재해 취약 | 태풍 직격 경로, 해안 침수 최고 위험 |

## 10. 미시분석 연계 — 건폐율 보정 필요성

### 실제 용도지역별 건폐율 (국토계획법 시행령 기준)

| 용도지역 | 법정 건폐율 | 현재 60% 대비 |
|---|---|---|
| 일반/준공업지역 | 70% 이하 | 과소 추정 (안전) |
| 계획관리지역 | 40% 이하 | 과대 추정 +20%p 주의 |
| 보전/생산관리지역 | 20% 이하 | 과대 추정 +40%p 위험 |
| 자연녹지지역 | 20% 이하 | 과대 추정 +40%p 위험 |
| 농림지역 | 20% 이하 | 과대 추정 +40%p 위험 |

### 토지이음 SHP 데이터 활용 개선 방안

다운로드한 KLIP 용도지역 SHP (강원·충북·전북·경북·광주·대전):

1. 격자-용도지역 공간조인 → 격자별 실제 용도지역 파악
2. 용도지역별 건폐율 적용 → 건폐면적 재산출
3. 새 하드 필터: 주거전용지역 등 데이터센터 행위제한 구역 제거
4. 새 소프트 스코어: 용도지역 적합성 (공업지역 100 ~ 보전관리 20)

현재 과대 추정된 건폐면적(특히 강원 춘천시 4,744ha)이 용도지역 반영 시 상당 감소 예상.
