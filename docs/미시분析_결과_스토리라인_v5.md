# AI 하이퍼스케일 데이터센터 최적입지 — 미시분석 결과 스토리라인 (v5)

> **분석 기준**: 250m 격자 / BFS 클러스터링 / 토지이음 용도지역 보정 / 6개 소프트 스코어
> **최종 업데이트**: 2026-05-24

---

## 1. 왜 미시분석인가

거시분석(시군구 단위)으로 15개 후보지역을 좁혔다면, 미시분석은 그 안에서 **실제 삽을 꽂을 수 있는 구체적인 부지**를 찾는 단계다.

| 거시분석 | 미시분석 |
|---|---|
| 시군구 단위 전력·냉각·재해 평가 | 250m 격자별 경사·도로·수계·법규 평가 |
| "청주시가 좋다" | "청주 오창읍 북쪽 577격자가 최적이다" |
| 전국 비교 → 15개 후보 선정 | 15개 후보 내 실제 부지 클러스터 특정 |

```
        ↓

```

## 4. 소프트 스코어 6종 — 가중치 설계

```
전력(변전소) 15% + 교통 20% + 경사도 25% + 냉각수 15% + 산업단지 10% + 용도지역 15% = 100%
```

### 전력/변전소 접근성 (15%)

- **지표**: 154kV 이상 변전소까지 거리 (0km=100점, 10km=0점)
- **데이터**: OpenStreetMap `power=substation, voltage=154000|345000|765000`
- **한계**: OSM은 자원봉사 기반 → 일부 소규모 변전소 누락 가능. "공개 OSM 기준" 명시 필요
- **경쟁 데이터**: 한국전력공사 변전소 GIS (비공개 보안 자료)

### 교통 접근성 (20%)

- **지표**: 고속도로 IC까지 거리 (3km 이내=100점, 25km 이상=10점)
- **데이터**: OSM `highway=motorway_junction`, 국도·지방도 포함
- **이유**: 서버 장비 반입, 유지보수 차량, 냉각수 약품 공급 → 물류 접근 필수

### 경사도 (25%) — 최고 가중치 이유

- **지표**: DEM 기반 경사 각도 (5도 이하=100점, 15도 이상=하드 필터 제거)
- **데이터**: NGII 수치고도모델 (1:5,000 / 5m 해상도)
- **이유**: 100MW급 대형 시설은 평지 요건이 절대적. 경사 1도 증가 = 기초 공사비 약 5~8% 증가
- **민감도**: 가중치 15~35% 변화 시에도 Top 5 순위 큰 변동 없음 (검증 완료)

### 냉각수 접근성 (15%)

- **지표**: 하천·수계까지 거리 (500m 이내=100점, 5km 이상=10점)
- **데이터**: OSM `waterway=river|stream|canal`
- **중요 한계**: 현재 지표는 "하천 근접성"이지 "실제 취수 가능성"이 아님
  - OSM stream(소하천)도 점수 부여됨 → 계곡이나 소하천 근처도 점수를 받을 수 있음
  - AI DC 수냉식 냉각 필요 수량: 100MW 기준 약 10~20만 톤/일
  - 소하천으로는 취수량 부족 → 4대강 본류(한강·금강·낙동강) 근접이 실질적으로 유리
  - 발표 시 표현: **"냉각수 근접 가능성 지표 (실제 취수량·수질 별도 검토 필요)"**
- **실제 Top5 수계 현황**:
  - 춘천: 북한강 본류 → 실질 취수 충분
  - 진천: 미호천(금강 지류) → 양호
  - 강릉: 남대천 → 제한 있음
  - 음성: 음성천·청미천 → 소하천 한계
  - 청주청원: 미호강 → 양호

### 산업단지 근접성 (10%)

- **지표**: 기존 산업단지(국가산단·일반산단)까지 거리
- **데이터**: OSM `landuse=industrial` + 공공데이터포털 산업단지 SHP (data.go.kr/15147806)
- **이유**: 전력 인프라·배수 시설·인력 공유 가능. 입지 경험 있는 지역일수록 인허가 빠름

### 용도지역 적합성 (15%) — v5 신규

- **지표**: 토지이음 용도지역별 데이터센터 적합성 점수
- **데이터**: 토지이음 KLIP SHP (UQ111 도시지역·UQ112 관리지역·UQ113 농림지역)
- **점수 매핑**:

| 용도지역 | 점수 | 건폐율 |
|---|---|---|
| 공업지역 (전용·일반·준) | 100 | 70% |
| 계획관리지역 | 80 | 40% |
| 상업지역 | 75 | 70~80% |
| 자연·생산녹지 | 35 | 20% |
| 관리지역 (생산·보전) | 20~40 | 20% |
| 농림지역 | 25 | 20% |
| 미지정 | 55 | 40% |

## 9. 분석 한계 및 주의 사항

1. **건폐 면적 = 건폐율 × 격자 면적**: 실제 개발 가능 면적은 기반시설(도로, 배수) 공제 후 더 줄어들 수 있음
2. **냉각수 지표**: 하천 거리 기반이며 실제 취수 가능량·수질 미반영 (4대강 본류 인근 지역이 유리)
3. **변전소 데이터**: OSM 기반 → 한전 내부 GIS 대비 일부 변전소 누락 가능
4. **'Top 5 후보지'**: 이 분석은 최종 입지 확정이 아니라 후보지 압축 단계. 실제 개발 시 지질조사·환경영향평가·지역주민 협의 필수
5. **용도지역 미지정(55%)**: 상당수 격자가 행정경계 내 용도지역 미지정으로 분류 → 추가 정밀 조사 필요
