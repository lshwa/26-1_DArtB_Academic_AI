# AI 하이퍼스케일 데이터센터 최적입지 분석 — 미시분석 방법론 및 데이터 출처

---

## 1. 분석 개요

본 미시분석은 거시분석에서 선정된 **전국 상위 15개 시군구**를 대상으로, 250m × 250m 격자 기반의 공간분석을 통해 **하이퍼스케일 데이터센터 입지 가능 클러스터**를 탐색한다.

| 항목 | 내용 |
|------|------|
| 분석 단위 | 250m × 250m 격자 (EPSG:5179 TM Korea 좌표계) |
| 격자 면적 | 62,500 m² (6.25ha) / 격자 |
| 건폐율 적용 | 60% → 격자당 건폐 가능 면적 37,500 m² |
| 하이퍼스케일 기준 | 인접 격자 4개 이상 연결 클러스터 (건폐면적 최소 150,000 m² = 15ha) |
| 최종 점수 산식 | 거시점수(정규화) × 0.30 + 미시클러스터점수 × 0.70 |

---

## 2. 분석 흐름

```
전국 행정경계 SHP
    ↓
시군구별 250m 격자 생성 (EPSG:5179)
    ↓
[하드 필터] 법적·지형 입지 불가 격자 제거 (10종)
    ↓
OSM 지역 데이터 다운로드 (Overpass API, bbox 방식)
    ↓
OSM 주거지·군사시설 하드 필터 추가 적용
    ↓
[소프트 스코어] 격자별 입지 적합도 0~100 산정
    (전력: OSM 거리 × KEPCO 여유용량 팩터)
    ↓
BFS 연결성분 탐색 → 하이퍼스케일 클러스터 도출
    ↓
최종 점수 = 거시 30% + 미시클러스터 70%
    ↓
Top 5 최적 입지 선정
```

## 3. 하드 필터 (입지 법적·지형 불가 지역)

격자가 아래 기준 중 하나라도 해당되면 분석에서 **완전 제외**.

### 3-1. 경사도 15도 초과

- **기준**: 격자 내 평균 경사도 > 15°
- **이유**: 대규모 건축물(하이퍼스케일 DC) 기초 공사 불가, 토사 재해 위험
- **데이터**: SRTM DEM v4.1 (NASA / CGIAR-CSI)
  - 파일: `srtm_62_05.tif`, `srtm_62_06.tif`
  - 커버리지: 125°E–130°E, 30°N–40°N
  - 공간해상도: 약 90m
  - 출처: https://srtm.csi.cgiar.org
- **계산**: NumPy 중앙차분법으로 경사 벡터 산출 → arctan(√(dz/dx² + dz/dy²))

### 3-2. 보전산지

## 4. 소프트 스코어 (격자별 입지 적합도 0~100)

하드 필터를 통과한 격자에 대해 6개 항목을 가중 합산하여 미시 점수 산정.

| 항목 | 가중치 | 데이터 출처 | 산정 방식 |
|------|--------|------------|----------|
| 전력 인프라 | **25%** | OSM 154kV+변전소 + **KEPCO 여유용량 CSV** | 거리 점수 × 여유용량 팩터 |
| 교통 접근성 | **20%** | OSM `highway=motorway/trunk/primary/secondary/tertiary` | 격자 중심~도로 거리, 0m=100점·3km=0점 |
| 경사도 | **25%** | SRTM DEM | 0°–5°=100점, 5°–15°=선형 감소, 15°+=0점 |
| 냉각수 접근성 | **15%** | OSM `waterway=river/stream/canal`, `natural=water` | 격자 중심~수계 거리, 0m=100점·5km=0점 |
| 산업단지 근접성 | **10%** | 한국산업단지공단 xlsx + Nominatim 지오코딩 + OSM industrial | 격자 중심~산업단지 거리, 0m=100점·10km=0점 |
| 민원 이격 | **5%** | OSM `landuse=residential` | 주거지 이격 거리, 0m=0점·2km=100점 (멀수록 유리) |

### 4-1. 전력 인프라 (25%) — KEPCO 여유용량 통합

하이퍼스케일 데이터센터(100–500MW급)는 154kV 이상 초고압 변전소에서 직접 전력 공급이 필수.

**거리 기반 점수 산식**:
```
s_dist = clip(1 - d_변전소 / 10000m, 0, 1)  → 0m=1.0, 10km=0.0
```

**KEPCO 여유용량 팩터 (신규 적용)**:
- 데이터: 한전 송전망 여유용량 현황 CSV (2026–2032년 연도별 여유용량 제공)
- 파일: `변전소_송전망여유용량.csv` — 1,311개 변전소
- 기준 연도: 2030년 여유용량 (`여유용량_2030_MW`)
- 산정:
  ```
  cap_factor = min(max_여유용량_해당시군구 / 300MW, 1.0)
  s_power = s_dist × cap_factor × 100
  ```
  - 300MW 이상 → 팩터 1.0 (만점 기준)
  - 150MW → 팩터 0.5 (절반 점수)
  - 0MW → 팩터 0.0 (전력 불가)
- **근거**: 하이퍼스케일 DC 1개동 기준 100–300MW 필요. 여유용량 미확보 지역은 설치 자체 불가.

- OSM 수집 변전소: 842개 (154kV·345kV·765kV)
- KDTree로 각 격자 중심~최근접 변전소 거리 산출

### 4-2. 교통 접근성 (20%)

건설 자재·서버 장비 반입, 유지보수 인력 접근을 위한 도로망 접근성.

### 4-3. 경사도 (25%)

평탄 부지는 기초 공사비 절감, 구조물 안전성 확보, 냉각탑 설치 등에 유리.

### 4-4. 냉각수 접근성 (15%)

데이터센터 냉각 시스템(쿨링타워)은 취수 가능한 하천·수계 인접 시 운영 비용 절감.

### 4-5. 산업단지 근접성 (10%)

기존 산업단지 인근은 전력·통신 인프라, 배후 서비스 단지가 갖춰져 있어 초기 투자비 절감.

### 4-6. 민원 이격 (5%)

주거지 근접 시 소음·냉각탑 증기·경관 민원 발생 가능성 증가. 2km 이상 이격 시 만점.

## 5. 하이퍼스케일 클러스터 탐색

### 5-1. 연결성분 탐색 (BFS)

- **인접 기준**: 격자 중심 간 거리 ≤ 375m (= 250m × 1.5, 상하좌우·대각 모두 포함)
- **알고리즘**: 너비 우선 탐색(BFS)으로 연결된 격자 집합 도출
- **최소 규모**: 4개 격자 이상 (건폐면적 150,000 m² = 15ha)

### 5-2. 클러스터 점수 산식

```
클러스터점수 = 평균소프트점수 × (1 + 0.15 × ln(n격자 + 1))
```

- **규모 보정**: 격자 수가 많을수록(대규모 클러스터) 보너스 부여 (최대 약 40%)
- **이유**: 하이퍼스케일 DC는 확장성(Phase 1→2→3)이 필수이므로 클러스터 크기를 반영

### 5-3. 최적 클러스터 선정

각 지역 내 최고 점수 클러스터 1개를 해당 지역의 대표 미시 점수로 채택.

## 6. 최종 점수 및 랭킹

```
최종점수 = 거시점수_정규화 × 0.30 + 최상위클러스터점수 × 0.70
```

- **거시점수 정규화**: Top15 지역 내 최고점=100, 최저점=0으로 선형 정규화
- **클러스터점수**: 각 지역 내 최상위 BFS 클러스터의 점수 (규모 보정 포함)
- **가중치 근거**: 미시 입지 가능 여부가 거시 인프라 우수성보다 실현 가능성에 더 직결됨

## 8. 행정경계 매칭 방법

`sigungu_all_korea.geojson` 내 `code` 컬럼(시군구 코드)을 활용한 4단계 매칭:

1. **1순위**: 시군구명 완전일치 + 시도 코드 접두사 일치
2. **2순위**: 시군구명 완전일치 (시도 무관)
3. **3순위**: 시군구명 앞 4자 접두 + 시도 코드 접두사
4. **4순위**: 시군구명 앞 3자 포함 + 시도 코드 접두사

시도별 코드 접두사:
```
광주=24, 대전=25, 강원=32, 충북=33, 전북=35, 경북=37 …
```

이를 통해 "대전 서구"와 "광주 서구", "포항시북구"와 "포항시남구" 등의 오매칭을 방지.

## 11. 분석 한계 및 향후 과제

- **공시지가**: 토지 취득 비용 미반영. 실제 사업성 평가 시 필수 항목
- **전력 여유용량 정밀 적용**: CSV에 수록된 여유용량은 시군구 단위 최대값 사용 — 실제 지점별 용량은 한전 개별 협의 필요
- **냉각 방식**: 수냉식·공냉식 혼합 고려. 연평균기온 데이터 미반영 — 강릉·춘천 등 냉량 지역 과소 평가 가능성
- **인허가**: 용도지역 (준공업지역·계획관리지역 여부) 미분석. 실제 건축 가능 여부는 개별 필지 단위 확인 필요
- **재생에너지 연계**: 태양광·풍력 가용 용량 미반영 — RE100 요건 충족 가능 지역 추가 평가 필요
- **통신 인프라**: 백본 광케이블 접속점 거리 미반영 — 초저지연 요구 서비스(금융·HFT)의 경우 수도권 인접성 재평가 필요
