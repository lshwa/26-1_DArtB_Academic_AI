# AI 하이퍼스케일 데이터센터 최적입지 분석 방법론

## 1. 분석 개요

본 분석은 국내 AI 하이퍼스케일 데이터센터 최적입지를 선정하기 위해
거시분석(지역 단위)과 미시분석(격자 단위) 2단계로 진행하였다.

|------|-----|

| 격자 크기 | 250m x 250m |
| 격자 면적 | 62,500 m2 |
| 건폐율 | 60% |
| 격자당 건폐 가능 면적 | 37,500 m2 (3.75ha) |

## 3. 하드 필터 (10종)

법적 규제 및 물리적 제약으로 개발 불가능한 격자를 제거한다.

| 번호 | 필터명 | 근거 |

| 1 | 경사도 > 15도 | DEM(수치고도모델) 기반 계산 |
| 2 | 보전산지 | 산지관리법 |
| 3 | 농업진흥지역 | 농지법 |

| 5 | 자연공원 (국립/도립/군립) | 자연공원법 |
| 6 | 개발제한구역 (그린벨트) | 개발제한구역법 |
| 7 | 백두대간 보호구역 | 백두대간보호에 관한 법률 |

## 4. 소프트 스코어 (6종)

하드 필터를 통과한 격자에 대해 입지 적합도를 0~100점으로 평가한다.

| 지표 | 가중치 | 계산 방법 | 비고 |
|------|--------|-----------|------|
| 변전소 접근거리 | 15% | 154kV+ 변전소까지 거리 (0m=100점, 10km=0점) | 미시 격자 단위 — 거시의 지역 여유용량과 구분 |
| 교통 접근성 | 20% | 주요 도로까지 거리 (0m=100점, 3km=0점) | OSM 도로망 |
| 경사도 | 25% | 0~5도=100점, 5~15도 선형감소 | DEM 기반 |
| 냉각수 접근성 | 20% | 하천/수계까지 거리 (0m=100점, 5km=0점) | OSM 수계 |
| 산업단지 근접성 | 15% | 산업단지까지 거리 (0m=100점, 10km=0점) | KEPCO/산업부 목록 |
| 민원 이격 | 5% | 주거지에서 멀수록 고점 (2km이상=100점) | OSM 토지이용 |

## 5. 클러스터링 방법론 (2단계 파이프라인)

### 5-1. BFS (너비 우선 탐색) — 물리적 연결성

인접 거리 375m (격자크기 x 1.5) 내 격자들을 연결하여 물리적으로
연속 배치 가능한 덩어리(연결 요소)를 탐색한다.

- 목적: 실제 건설 가능한 연속 부지 확보
- 최소 격자 수: 4개 이상 (최소 15ha)
- 클러스터 점수 = 평균 소프트점수 x (1 + 0.15 x ln(격자수 + 1))

### 5-2. BFS+Spectral — 특성 균질 핵심 구역

BFS로 정의된 연결 구역 내부에서 Spectral Graph Clustering을 적용하여
입지 특성이 가장 균질한 핵심 구역을 선별한다.

- 엣지 가중치: 가우시안 커널 W_ij = exp(-(s_i - s_j)^2 / 2 sigma^2)
- 라플라시안 eigengap으로 최적 k 결정 (2 <= k <= 5)
- n > 3000: KMeans on spectral embedding (메모리 효율)
- 결과: BFS 연결성 + Spectral 균질성을 동시에 보장

## 6. 최종 점수 산출

```
최종점수 = 거시점수_정규화 x 0.30 + 클러스터점수 x 0.70
```

- 거시점수_정규화: Top15 내 0~100 min-max 정규화
- 클러스터점수: 채택된 클러스터의 점수 (BFS+Spectral 우선)
